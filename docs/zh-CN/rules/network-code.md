# 网络代码规则

- 服务器对所有玩法关键状态拥有权威(authoritative)——绝不信任客户端
- 所有网络消息必须带版本号,以保证前向/后向兼容
- 客户端本地预测,与服务器对账(reconcile)——对预测错误实现回滚
- 优雅处理断线、重连和主机迁移
- 对所有网络日志做限流,防止日志洪泛
- 所有联网数值必须指定复制策略:可靠/不可靠、频率、插值
- 带宽预算:定义并跟踪每种消息类型的带宽用量
- 安全:校验所有入站数据包的大小和字段范围
